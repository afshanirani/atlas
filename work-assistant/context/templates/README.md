# Templates

Repeating structures in the work. `epic-scaffold` instantiates these; `spec-draft` uses
the outline ones.

Most PM work has more repetition than it appears to — the same deliverable set per
initiative, the same launch checklist, the same spec skeleton. Each one written down here
is manual assembly you stop doing.

## Files

- `epic-template.md` — the pattern for a repeating deliverable set
- `prd-outline.md` — spec skeleton
- `status-update.md` — recurring update format

## Adding a template

You've found one when you notice yourself creating the same set of items a second time.
Write it down on the second occurrence, automate it on the third.

Record what **varies** between instances as parameters. Anything that differed across
past instances is a parameter, not a constant — hardcoding it produces confidently wrong
scaffolding.
