# Skills

Capability growth. Nothing else in the stack tracks this — task systems record what you
did, never what you learned.

`last_verified: TODO`

## Template

```
## <Skill>

- **Level:** exploring | applying | proficient | can teach it
- **Learned via:** [[initiative]], course, or self-directed
- **Evidence:** the specific artifact you produced with it
- **Started:** YYYY-MM-DD
- **last_verified:** YYYY-MM-DD
```

## What to track

Both halves of a technical PM's growth:

- **Technical:** platforms, data and query skills, architecture literacy, domain depth
- **Craft:** discovery methods, prioritization frameworks, stakeholder management,
  writing, running a cadence

## Notes

- **Evidence must be concrete.** "Familiar with the data platform" is worthless at review
  time; "built the lineage requirements for X" is not.
- **Populated by `context-capture`, not by sitting down to fill it in.** Skills are
  recorded as they're acquired or not at all.
- Downstream consumers: performance reviews, promotion cases, résumé material, and
  deciding what to learn next. Keep entries dated so growth is visible over time.
